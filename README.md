# Sebastiaan Fehr - Resume

A personal resume website for Sebastiaan Fehr, a Studio/Technical Director and senior game developer.

The site is a responsive, print-friendly static page built with HTML and CSS. It highlights professional experience, technical skills, education, and contact details.

## Local preview

Open `index.html` directly in a browser, or serve the repository with any static file server. For example:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project structure

- `index.html` - page content and styles
- `headshot.png` - profile image
- `icon-popout.svg` - external-link icon
- `CNAME` - custom domain configuration

## Deployment

The site is hosted with GitHub Pages at [seb.fehr.work](https://seb.fehr.work).
